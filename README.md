# 薄膜による光の干渉

高校物理の授業向けのシミュレーションです。外部ライブラリ・外部フォント・ビルドは不要です。

## 起動

Node.js 22 以降で、プロジェクトフォルダーから実行します。

```powershell
npm run dev
```

[http://127.0.0.1:4173](http://127.0.0.1:4173) をブラウザーで開いてください。ES Modules を使うため、HTML のダブルクリックではなく HTTP サーバーから開きます。

## 操作

- 下部のスライダーで、真空中の波長（380〜750 nm）、膜厚（0〜1,000 nm）、法線からの入射角（0〜70°）を変更します。
- 入射光上の丸いハンドルで角度、膜の下面のハンドルで膜厚をドラッグできます。マウス・タッチ・ペンに対応しています。
- 各媒質の屈折率は 0.5〜2.5 の範囲で入力できます。
- 平面波は山を実線、谷を破線で表示します。波形表示は合成波／個別波を切り替えられます。
- 入射波は青、反射波は橙です。波形の個別波表示では下面反射が紫の破線になります。色は経路の区別を表し、波長の違いを表しません。
- 波形表示では別々の位置から入射する2本を描き、上面反射と膜内を一往復した反射を同じ出射点から観測者へ向けて重ねます。媒質をまたぐ波形は光学距離に応じた位相を引き継いだ連続曲線です。合成波は出射点の少し先から表示します。
- 「経路差」は初期状態ではオフです。オンにすると膜内の往復と、差し引く上側の参照経路を表示します。
- 一時停止、リセット、説明、対応ブラウザーでの全画面表示を利用できます。OS の「視差効果を減らす」設定では初期状態が停止になります。

## 計算モデル

単色光・s 偏光、吸収のない媒質を仮定します。スネルの法則から屈折角を計算し、光路差を `Δ = 2 n₂ d cos θ₂`、伝搬による位相差を `2πΔ/λ` として、上面の直接反射と膜内を一往復した反射の二光束を合成します。振幅には s 偏光のフレネル係数 `r₁₂` と `t₁₂ t₂₁ r₂₃` を使用します。多重反射は含みません。

屈折率が大きい側での反射は位相が π 変わり、小さい側での反射は変わりません。下面で全反射する場合は複素フレネル係数の位相を使用します。上面で全反射する場合は単一の反射光だけを描きます。エバネッセント波や薄膜を通じたしみ出しは扱いません。臨界角そのものは伝搬光の描画から除いています。

強め合う／弱め合うの表示は反射位相を含めた相対位相で判定します。強度バーは二光束が同位相であるときの最大強度で規格化した値であり、入射光に対する反射率ではありません。実際の振幅が異なるため、弱め合ってもゼロにならない場合があります。模式図の拡大率は屈折角・画面サイズに合わせて調整します。

光路差マーカーの黄は AB + BC（膜内）です。平面波表示の桃は AD（媒質 1）で、C と D は反射光の進行方向に垂直な同じ面上にあり、`Δ = n₂(AB + BC) − n₁ AD` です。波形表示では①の入射経路の DC が桃色になり、A と D が入射光の同一波面上にあるため `Δ = n₂(AB + BC) − n₁ DC` です。いずれも `2 n₂ d cos θ₂` に一致します。屈折率による光学的な距離と幾何学的な距離を区別します。

参考：[OpenStax, University Physics Vol. 3, §3.4](https://openstax.org/books/university-physics-volume-3/pages/3-4-interference-in-thin-films)、[University of Tennessee, Thin film interference](https://labs.phys.utk.edu/mbreinig/phys421/modules/m6/Thin%20film%20Interference.html)。

## GitHub Pages

リポジトリの **Settings → Pages → Source** を **GitHub Actions** に設定してください。`main` への push、または Actions の手動実行で `.github/workflows/pages.yml` がテスト・構文チェック後に静的ファイルを公開します。

公開するファイルは `index.html`、`styles.css`、`app.js`、`physics.mjs`、`wave-path.mjs` の 5 点です。すべて相対 URL のため、GitHub Pages のサブディレクトリーに対応します。サーバーや認証情報は不要です。

## 検証

```powershell
npm test
npm run check
```

テストでは垂直入射の強め合い／弱め合い、2 回の反転、斜入射の光路差、屈折率一致、全反射、入力範囲内の計算結果を確認します。

制作時には Chromium で 320×568、390×844、768×1024、844×390、1024×768、1180×820、1366×768、1920×1080 の画面内への収まりを確認しました。マウスによる膜厚・角度のドラッグ、キーボード操作、表示切り替え、数値入力、リセット、説明画面を検証しています。また、タッチを模擬した環境で膜厚ドラッグ、スライダー、経路差スイッチ、表示切り替え、画面回転を確認しました。

ブラウザー上の画面サイズ・タッチの検証は実機の動作保証とは異なります。iPad の Safari・Chromebook での実機確認は別途必要です。
